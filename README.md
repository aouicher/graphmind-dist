# graphmind — DEPRECATED

> **This repository has moved.**
>
> graphmind is now open source and maintained at **[aouicher/graphmind](https://github.com/aouicher/graphmind)**.
>
> This repository (`aouicher/graphmind-dist`) is no longer updated.
> The last release here (v0.2.165) contains an automatic migration — running `graphmind update` will redirect you to the new repo.

## Migrate

```bash
graphmind update
```

Or reinstall from the new home:

```bash
curl -fsSL https://raw.githubusercontent.com/aouicher/graphmind/main/scripts/install.sh | bash
```

## Homebrew

```bash
brew update
brew upgrade graphmind
```
